# GRUB Theme Builder

### Visual GRUB 2 Theme Design Studio for Windows and Linux

**GRUB Theme Builder** is a visual design and editing tool for creating, customizing, previewing, importing, and exporting **GRUB 2 themes**.

Instead of manually editing `theme.txt` and managing every resource separately, you can design your GRUB interface visually on a graphical canvas.

## ✨ Features

### 🎨 Visual Theme Editor
- Visual canvas-based theme design
- Drag, position, and resize elements
- Add text, images, boxes, and progress indicators
- Customize colors and transparency
- Zoom and preview the design
- Save and reopen projects
- Import and export GRUB themes

### 🖼️ Background System

Three background modes are available:

- **Simple Color** — single-color background
- **Background Studio** — create graphical backgrounds directly in the application
- **External Image** — use an existing image

### 🎨 Background Studio

Create custom backgrounds using:

- Multi-color gradients
- Custom colors and transparency
- Circles, squares, and cubes
- Lines, waves, and arrows
- Decorative and layered elements

### 📋 Boot Menu Studio

Design the GRUB boot menu as a complete visual component.

Customize:

- Position and size
- Text and colors
- Transparency
- Borders and rounded corners
- Shadows
- Light and glow
- Glass-style appearance

### 🔤 Font Management

GRUB Theme Builder supports:

- `.ttf`
- `.otf`
- GRUB `.pf2`

Fonts can be automatically converted from **TTF/OTF to PF2** during the export workflow.

**Windows:** bundled GRUB font conversion tools are included.

**Linux:** the application uses the system-installed `grub-mkfont`.

### 📊 Progress Indicators

Create and customize:

- Progress bars
- Circular progress indicators

Both support positioning, sizing, colors, transparency, and visual customization.

### 📝 Text & Images

Add and customize text and images directly on the canvas.

Text supports:

- Font
- Size
- Color
- Transparency
- Position

Images can be imported, resized, positioned, and included in the exported theme.

### 📦 Boxes & UI Elements

Create panels and interface elements with:

- Custom colors
- Transparency
- Borders
- Rounded corners
- Position and size

### ✨ Visual Effects

Supported visual effects include:

- Transparency
- Shadows
- Light
- Glow
- Glass-style effects
- Rounded corners
- Borders
- Gradients

## 📥 Import

Existing GRUB themes can be imported and edited.

Supported elements and properties depend on the structure and features used by the original theme.

## 📤 Export

Projects can be exported as GRUB 2 themes with resources such as:

```text
theme.txt
fonts/
images/
icons/
```

Font conversion is integrated into the export process.

## 💾 Project Files

GRUB Theme Builder uses its own project format:

```text
.GthEri
```

Projects can be saved and reopened without rebuilding the theme from scratch.

## 🚀 Workflow

```text
Create Project
      ↓
Choose Background
      ↓
Design Background
      ↓
Design Boot Menu
      ↓
Add Theme Elements
      ↓
Choose Font
      ↓
Apply Effects
      ↓
Preview
      ↓
Export GRUB Theme
```

## 🖥️ Supported Platforms

### Windows
Includes the application runtime and bundled GRUB font conversion tools.

### Linux
Uses the system's `grub-mkfont` installation for font conversion.
