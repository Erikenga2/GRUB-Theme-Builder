# GRUB Theme Builder

**GRUB Theme Builder** is a free visual **GRUB 2 theme editor and builder** for Windows and Linux.

It allows you to **create, edit, preview, import, and export GRUB 2 bootloader themes** using a graphical interface. Instead of manually editing `theme.txt` files and calculating the position of every element, you can design your GRUB theme visually on a canvas.

GRUB Theme Builder is designed for both beginners who want an easier way to create GRUB themes and experienced Linux users who want a visual tool for customizing existing themes.

- 🎨 Visual GRUB 2 theme editor and builder

## 🎯 What Is GRUB Theme Builder?

GRUB Theme Builder is a **GUI tool for creating and editing GRUB 2 themes**.

A GRUB theme controls the visual appearance of the GRUB bootloader, including elements such as text, images, boxes, progress indicators, and boot menus.

Traditionally, creating a GRUB theme requires manually editing configuration files and calculating element positions. GRUB Theme Builder provides a visual canvas where these elements can be positioned and configured graphically.

This makes GRUB theme design easier without requiring every element to be positioned manually in a text editor.

## 🖥️ Visual GRUB Theme Editor

The main part of GRUB Theme Builder is its graphical design canvas.

You can add and configure different GRUB theme elements, including:

- Labels
- Images
- Boxes
- Progress bars
- Circular progress indicators
- Boot menus

Elements can be positioned visually on the canvas and their properties can be customized.

The visual editor is useful when creating a new GRUB theme from scratch as well as when modifying an existing GRUB theme.

## 🛠️ What Can You Do With It?

GRUB Theme Builder can be used to:

- Create a GRUB 2 theme from scratch
- Edit an existing GRUB theme
- Design custom GRUB bootloader screens
- Customize GRUB colors and transparency
- Position GRUB theme elements visually
- Create and edit GRUB boot menus
- Add images and text to a theme
- Customize boxes and progress indicators
- Preview and adjust a design before exporting
- Save a project and continue editing it later
- Import an existing GRUB theme and modify it
- Export the finished GRUB theme

## 📥 Import Existing GRUB Themes

GRUB Theme Builder can import existing GRUB themes for editing.

After importing a theme, you can use the visual editor to customize supported elements, change properties, modify the design, and rearrange elements.

This makes it possible to customize an existing GRUB theme without rebuilding the entire design from scratch.

## 📤 Export GRUB Themes

When your design is complete, GRUB Theme Builder can export the theme files.

The exported files can then be used as a GRUB 2 theme on compatible Linux systems.

## 💾 Project Files

GRUB Theme Builder uses its own project format for saving editable projects.

Project files use the:

```text
.GthEri
```

extension.

This allows you to save your work and continue editing the project later without rebuilding the theme from the beginning.

### Create a GRUB Theme

1. Open **GRUB Theme Builder**.
2. Create a new project.
3. Add images, labels, boxes, progress bars, boot menus, or other supported elements.
4. Position the elements on the canvas.
5. Configure their properties.
6. Preview the design.
7. Save the project if you want to continue editing it later.
8. Export the finished GRUB theme.
